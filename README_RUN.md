# 矮人礦坑：終端機可遊玩版執行說明

## 檔案

```text
main.c              終端機輸入與畫面流程
game.h / game.c     遊戲與每輪初始化
card.h / card.c     牌庫資料
rule.h / rule.c     出牌與連通規則
score.h / score.c   金塊牌與計分
Makefile            編譯與測試指令
```

## Linux / macOS 編譯與執行

在所有檔案所在資料夾執行：

```bash
make test
make run
```

不使用 Makefile 時可手動編譯：

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic -Werror -I. \
    main.c game.c card.c rule.c score.c -o saboteur
./saboteur
```

## Windows MinGW

```powershell
gcc -std=c11 -Wall -Wextra -Wpedantic -Werror -I. main.c game.c card.c rule.c score.c -o saboteur.exe
.\saboteur.exe
```

## 遊玩方式

1. 輸入 3–10 位玩家名稱。
2. 程式隨機排列遊玩順序並顯示第一輪起始玩家。
3. 每輪開始時，依畫面提示傳遞裝置，每位玩家私密查看角色。
4. 公開畫面顯示版圖、工具損壞狀態與目前玩家；輪到的玩家進入私人畫面查看手牌並操作。
5. 終端機版放置坑道牌時，以 `row`、`col` 座標選擇空格；可選擇將牌旋轉 180 度。
6. 每輪結束公開角色；金塊分配仍以傳遞裝置的方式秘密完成。
7. 三輪後公開總金塊數與勝者。

## 終端機版符號

| 符號 | 意義 |
|---|---|
| `S` | 起點 |
| `?` | 尚未公開的終點 |
| `$` | 已翻開的金礦終點 |
| `X` | 已翻開的石頭終點 |
| `-` / `|` | 橫向 / 直向坑道 |
| `+` | 四向連通坑道 |
| `T` / `L` | 分岔或轉彎坑道 |
| `d` | 死路牌 |

## 此版本規則設定

- 新放置坑道必須透過通道連回起點。
- 放置在版圖上的坑道牌不會進入棄牌堆；落石移除的坑道牌才會與落石牌一起棄置。
- 金塊牌整局共用，使用標準 28 張配置：16 張 1 金塊、8 張 2 金塊、4 張 3 金塊。
- 淘金矮人成功時，依本輪實際淘金矮人人數抽取金塊牌並秘密選取。
- 下一輪由上一輪最後出牌者左側的玩家開始。
- 依你原本的數位遊戲設計，第一輪的遊玩順序由程式隨機排列；實體規則原本是由最年輕玩家先開始。
